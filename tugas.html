Cara Mengumpulkan Tugas ke Dosen

1
Tambah & Lengkapi Tugas:

Klik tombol "Tambah Tugas Baru". Masukkan nama mata kuliah, judul, deskripsi materi, dan upload berkas laporan atau foto hasil tugas/praktikum.

2
Jika Tugas Berupa Foto / Gambar:

Anda dapat menaruh file foto di folder images/ lalu isi kolom URL Foto (misal: images/tugas-jaringan.jpg), atau upload langsung saat mengisi form.

3
Simpan ke GitHub:

Klik tombol "Ekspor JSON (GitHub)", ganti isi file data/tugas.json, lalu jalankan git push agar tugas tampil secara publik untuk dosen.

4
Kirimkan Link ke Dosen:

Klik tombol Kirim ke Dosen pada kartu tugas yang bersangkutan. Link unik akan otomatis disalin ke clipboard Anda untuk dikirim via WhatsApp, Email, atau Google Classroom / LMS!

Sinkronisasi Cloud Multi-User (GitHub Pages)

Status: Mode Lokal (IndexedDB) Data tersimpan di browser Anda & static JSON. Hubungkan ke Supabase agar teman mahasiswa lain bisa ikut mengunggah secara online & realtime di GitHub Pages!
Panduan Setup Supabase (Gratis ± 2 Menit):
  1. Buka supabase.com dan buat akun gratis (bisa langsung pakai GitHub).
  2. Klik New Project, beri nama misalnya "tugas-kuliah".
  3. Buka menu SQL Editor di dashboard Supabase, klik tombol "Salin SQL Tabel" di atas, tempel di editor lalu klik Run.
  4. Buka Project Settings → API, salin Project URL dan anon public key ke form di atas (atau tempel di file js/supabase-config.js) lalu commit & push ke GitHub!
